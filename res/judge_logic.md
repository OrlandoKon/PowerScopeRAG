## 二、判断逻辑清单

### 2.1 身份冒用欺诈

#### 逻辑卡片 1.1：盗用身份申请贷款

| 字段 | 内容 |
|------|------|
| **原因名称** | 盗用身份申请贷款 |
| **所属分类** | 身份冒用欺诈 > 盗用身份申请 |
| **业务定义** | 使用他人的身份信息（身份证号、姓名、手机号等）提交贷款申请，获取贷款后失联 |
| **判断所需数据源** | 申请信息（姓名、证件号、手机号、地址）、设备信息（设备ID、IP地址、GPS）、征信数据（查询次数、历史账户）、行为数据（申请耗时、页面停留时间） |
| **关键数据特征** | ① 同一设备ID在30天内关联3个以上不同身份证号的申请；② 申请填写的手机号注册时间不足7天；③ IP地址与申请人身份证归属地不在同一省份；④ 申请表单填写速度异常快（整体耗时<3分钟，暗示使用自动填充工具）；⑤ 申请人手机号近期与已知欺诈用户的手机号存在通讯记录 |
| **判定阈值** | 满足上述特征中≥3项，判定为高风险；满足2项为中风险；满足1项为低风险 |
| **与其他类型区分** | 与"信息包装"(3.4)的区别：盗用身份是使用他人的身份，信息包装是使用自己的真实身份但虚报收入等信息。判断依据是申请身份与设备/行为历史的一致性——完全不一致倾向盗用，部分信息夸大倾向包装 |
| **历史典型案例参考** | 中介机构收购农村老人身份证件，批量在线上平台申请小额贷款，单笔金额控制在5000元以内以降低审核门槛 |

#### 逻辑卡片 1.2：信用卡盗刷

| 字段 | 内容 |
|------|------|
| **原因名称** | 信用卡盗刷 |
| **所属分类** | 身份冒用欺诈 > 信用卡盗刷 |
| **业务定义** | 未经持卡人授权，使用其信用卡信息（卡号、CVV、有效期等）进行线上或线下消费 |
| **判断所需数据源** | 交易数据（金额、时间、商户类别码MCC）、支付卡信息（card1-card6，对应IEEE-CIS数据集）、设备信息（DeviceType、DeviceInfo）、地址信息（addr1/addr2）、邮箱信息（P_emaildomain、R_emaildomain） |
| **关键数据特征** | ① 交易金额超过该卡近30天平均交易金额的5倍；② 交易设备与该卡近90天的历史绑定设备完全不匹配；③ 交易地址与持卡人注册地址距离>500公里；④ 同一张卡在1小时内出现≥3笔交易；⑤ 交易时间在凌晨2:00-5:00，且持卡人历史上从未在此时段消费；⑥ 收货邮箱域名与持卡人注册邮箱域名不同 |
| **判定阈值** | 满足≥3项特征判定为高风险，满足2项为中风险，满足1项为低风险 |
| **与其他类型区分** | 与"刷单套现"(2.1)的区别：盗刷消费通常指向真实商户的真实商品，金额不规律；套现通常指向虚假商户或低风险商户，金额呈规律性整数特征。与"异常时空交易"(2.4)的区别：盗刷的设备/地址与持卡人历史完全不一致，异常时空交易可能只是持卡人本人的非常规行为 |
| **历史典型案例参考** | 卡信息通过钓鱼网站泄露后，欺诈者在凌晨3点使用境外IP、陌生设备进行多笔高额电子产品购买 |

#### 逻辑卡片 1.3：伪造证件材料

| 字段 | 内容 |
|------|------|
| **原因名称** | 伪造证件材料 |
| **所属分类** | 身份冒用欺诈 > 伪造证件材料 |
| **业务定义** | 提交伪造的身份证件、收入证明、工作证明、银行流水等材料以通过审核 |
| **判断所需数据源** | 申请材料文本内容、申请人自报信息、第三方验证数据（如工商注册信息、社保记录） |
| **关键数据特征** | ① 申请人自报的工作单位在工商系统中查无此公司，或公司注册时间<6个月；② 自报月收入与所填行业/职位的市场薪资水平偏差>100%；③ 提交的银行流水中，入账金额呈现高度规律性（每月同一天、同一金额，且来源单一）；④ 多份不同申请人的材料在文件格式、字体、措辞上高度相似（暗示同一模板批量生成）；⑤ 申请人的社保缴纳记录与自报工作单位不一致 |
| **判定阈值** | 满足≥2项判定为高风险 |
| **与其他类型区分** | 与"盗用身份"(1.1)的区别：伪造材料使用的可能是本人身份但配以虚假证明文件，盗用身份是整个身份都是他人的。判断依据是核心身份信息（身份证号）是否属于申请人本人 |

#### 逻辑卡片 1.4：账户接管

| 字段 | 内容 |
|------|------|
| **原因名称** | 账户接管 |
| **所属分类** | 身份冒用欺诈 > 账户接管 |
| **业务定义** | 通过社工攻击、钓鱼、撞库等手段获取合法用户的账户控制权，冒充该用户进行操作 |
| **判断所需数据源** | 登录日志（时间、IP、设备指纹、地理位置）、账户操作记录（密码修改、手机号变更、提现地址变更）、历史行为基线 |
| **关键数据特征** | ① 登录设备、IP、地理位置同时发生变化，且与历史记录完全无交集；② 登录后立即修改密码或绑定手机号；③ 修改安全设置后短时间内（<1小时）发起大额提现或转账；④ 登录时间戳与该用户历史活跃时段严重不符；⑤ 连续多次登录失败后突然成功（暗示撞库攻击） |
| **判定阈值** | 特征①+②+③同时满足，直接判定为高风险 |
| **与其他类型区分** | 与"信用卡盗刷"(1.2)的区别：账户接管是获取了完整的账户控制权（可修改设置），盗刷只是获取了支付凭证（卡号/CVV） |

### 2.2 交易欺诈

#### 逻辑卡片 2.1：刷单套现

| 字段 | 内容 |
|------|------|
| **原因名称** | 刷单套现 |
| **所属分类** | 交易欺诈 > 刷单套现 |
| **业务定义** | 通过虚构交易（无真实商品或服务交付），利用信用卡或支付工具套取现金 |
| **判断所需数据源** | 交易数据（金额、商户类别码MCC、商户ID）、交易频率统计、退款记录 |
| **关键数据特征** | ① 交易金额呈现规律性整数特征（如反复出现9999元、4999元）；② 交易商户为高风险MCC类别（如珠宝、电子产品、虚拟商品）；③ 同一用户与同一商户频繁交易，但交易金额每次不同（模拟真实消费）；④ 高比例的交易在完成后短期内退款（T+1至T+3）；⑤ 交易时间高度集中（如均发生在工作日的10:00-11:00） |
| **判定阈值** | 满足≥3项判定为高风险 |
| **与其他类型区分** | 与"信用卡盗刷"(1.2)的区别：套现通常是持卡人本人操作（设备/IP与历史一致），盗刷是他人操作（设备/IP与历史不一致）。与"分拆交易"(2.2)的区别：套现的核心目的是取现，分拆的核心目的是规避监控阈值 |

#### 逻辑卡片 2.2：分拆交易

| 字段 | 内容 |
|------|------|
| **原因名称** | 分拆交易 |
| **所属分类** | 交易欺诈 > 分拆交易 |
| **业务定义** | 将一笔大额交易故意拆分为多笔小额交易，以规避大额交易监控或报告阈值 |
| **判断所需数据源** | 交易序列数据（金额、时间间隔、收款方）、大额交易报告阈值（中国为人民币5万元） |
| **关键数据特征** | ① 短时间内（如24小时内）向同一收款方发起多笔交易，单笔金额均略低于监控阈值（如49000元、49500元）；② 多笔交易的金额之和达到或超过大额报告阈值；③ 交易间隔呈现规律性（如每隔30分钟一笔）；④ 交易备注/摘要内容高度相似或为空 |
| **判定阈值** | 24小时内向同一收款方发起≥3笔交易，且单笔金额在阈值的80%-100%区间内，判定为高风险 |
| **与其他类型区分** | 与"快进快出"(4.1)的区别：分拆的资金流向是单向的（付款方→收款方），快进快出的特征是资金在同一账户快速中转（进来后立即转出到其他账户） |

#### 逻辑卡片 2.3：高频小额试探

| 字段 | 内容 |
|------|------|
| **原因名称** | 高频小额试探 |
| **所属分类** | 交易欺诈 > 高频小额试探 |
| **业务定义** | 使用盗取的卡信息进行多笔极小额交易（通常<10元），测试卡的有效性，成功后再进行大额消费 |
| **判断所需数据源** | 交易序列（金额、时间戳、成功/失败状态）、商户信息 |
| **关键数据特征** | ① 连续出现多笔金额<10元的交易（如1元、2元、5元）；② 这些小额交易的时间间隔极短（<5分钟/笔）；③ 小额交易成功后，紧接着出现一笔或多笔大额交易（>1000元）；④ 小额交易的商户多为低审核门槛的线上平台；⑤ 交易过程中出现多次失败记录（卡号无效、CVV错误等） |
| **判定阈值** | 1小时内出现≥5笔金额<10元的交易，或者出现≥3次支付失败后成功的模式，判定为高风险 |
| **与其他类型区分** | 与"刷单套现"(2.1)的区别：试探的金额极小且目的是验证卡的有效性，套现的金额相对较大且目的是提取资金 |

#### 逻辑卡片 2.4：异常时空交易

| 字段 | 内容 |
|------|------|
| **原因名称** | 异常时空交易 |
| **所属分类** | 交易欺诈 > 异常时空交易 |
| **业务定义** | 交易发生的时间、地点或时空组合严重偏离用户的历史行为模式 |
| **判断所需数据源** | 交易时间戳、交易地理位置（或IP归属地）、用户历史交易的时间/位置分布 |
| **关键数据特征** | ① 两笔相邻交易的地理位置之间的实际距离，按时间间隔计算的移动速度>800km/h（物理不可达）；② 交易发生在凌晨2:00-5:00，但用户过去90天从未在此时段有交易记录；③ 交易地点位于用户从未出现过的国家/地区；④ 单日内交易覆盖≥3个不同城市 |
| **判定阈值** | 满足①直接判定为高风险；满足②③④中任意2项判定为中风险 |
| **与其他类型区分** | 注意：异常时空交易不一定是欺诈，也可能是用户真实出差/旅行。需结合其他维度综合判断——如果设备指纹与历史一致，则偏向正常行为；如果设备指纹也变了，则偏向欺诈 |

### 2.3 信用欺诈

#### 逻辑卡片 3.1：首贷即骗

| 字段 | 内容 |
|------|------|
| **原因名称** | 首贷即骗 |
| **所属分类** | 信用欺诈 > 首贷即骗 |
| **业务定义** | 新注册用户在获取第一笔贷款后立即失联，从无偿还意图 |
| **判断所需数据源** | 用户注册信息、账龄、首笔贷款申请时间、贷后行为（还款记录、APP活跃度）、征信数据 |
| **关键数据特征** | ① 账户注册后极短时间内（<72小时）即申请贷款；② 直接申请最高可用额度；③ 贷款发放后，用户APP登录频率骤降至零；④ 首笔还款日逾期，且联系电话无法接通；⑤ 征信记录中无任何历史贷款记录（"白户"）；⑥ 注册手机号为近期新开卡号（开卡时间<30天） |
| **判定阈值** | 满足①+②+⑤同时成立，判定为高风险 |
| **与其他类型区分** | 与"养号欺诈"(3.3)的区别：首贷即骗的账户通常无任何养号行为，注册即申请，周期极短；养号是经过较长时间的正常使用后再集中骗贷 |

#### 逻辑卡片 3.2：多头借贷

| 字段 | 内容 |
|------|------|
| **原因名称** | 多头借贷 |
| **所属分类** | 信用欺诈 > 多头借贷 |
| **业务定义** | 借款人同时在多个平台借贷，以贷养贷，总负债远超还款能力，最终全面违约 |
| **判断所需数据源** | 征信查询记录、现有贷款余额、月还款额与月收入比（DTI）、近期新增贷款笔数 |
| **关键数据特征** | ① 近30天内征信被查询≥5次（不同机构）；② 现有未结清贷款≥3笔；③ 月还款总额/月收入（DTI）>60%；④ 近90天内新增贷款≥2笔；⑤ 近6个月内在≥3个不同平台有借款记录 |
| **判定阈值** | ①+③同时满足判定为高风险；仅满足①或③判定为中风险 |
| **与其他类型区分** | 与"首贷即骗"(3.1)的区别：多头借贷的用户通常有一定的信贷历史（非白户），初期可能还正常还款，后期才崩溃；首贷即骗是从一开始就无偿还意图 |

#### 逻辑卡片 3.3：养号欺诈

| 字段 | 内容 |
|------|------|
| **原因名称** | 养号欺诈 |
| **所属分类** | 信用欺诈 > 养号欺诈 |
| **业务定义** | 中介机构或个人通过长期维护账户（正常消费、按时还款），使账户获得高信用评级后集中骗贷 |
| **判断所需数据源** | 账户历史行为序列（时间跨度、行为模式）、消费特征、还款模式、设备信息 |
| **关键数据特征** | ① 账户活跃期内的消费行为模式高度规律（如每月固定日期、固定金额消费，缺乏真实用户的随机性）；② 账户达到高信用评级后，行为模式突然改变（从小额高频变为大额低频）；③ 多个账户的行为模式高度相似（暗示同一中介批量操作）；④ 账户绑定的设备ID在多个不同身份的账户上出现过；⑤ 达到高信用额度后立即申请最高额度贷款并快速提现 |
| **判定阈值** | ①+⑤同时满足或③+④同时满足，判定为高风险 |
| **与其他类型区分** | 与"首贷即骗"(3.1)的区别：养号有较长的"正常使用"期（通常3-12个月），首贷即骗几乎无正常使用期。养号的关键识别点在于正常期内行为的"过于规律"和信用提升后行为的"突然转变" |

#### 逻辑卡片 3.4：信息包装

| 字段 | 内容 |
|------|------|
| **原因名称** | 信息包装 |
| **所属分类** | 信用欺诈 > 信息包装 |
| **业务定义** | 使用本人真实身份，但虚报收入、工作单位、资产状况等信息以获取更高贷款额度 |
| **判断所需数据源** | 申请信息（自报收入、职业、工作年限）、第三方验证数据（社保缴纳基数、公积金记录）、行业薪资基准数据 |
| **关键数据特征** | ① 自报月收入与社保缴纳基数推算的收入偏差>50%；② 自报职位级别与工作年限不匹配（如工作2年自报总监）；③ 自报月收入位于所填行业/城市薪资分布的95%以上百分位；④ 同一申请人在不同平台填写的收入信息不一致（偏差>30%）；⑤ 自报工作单位的企业规模/行业与自报薪资水平不匹配 |
| **判定阈值** | 满足≥2项判定为中风险（信息包装通常不直接归为高风险，需结合信用评估综合判定） |

### 2.4 洗钱/资金异常流转

#### 逻辑卡片 4.1：快进快出

| 字段 | 内容 |
|------|------|
| **原因名称** | 快进快出 |
| **所属分类** | 洗钱/资金异常流转 > 快进快出 |
| **业务定义** | 资金进入账户后极短时间内全部转出，账户仅作为资金中转站 |
| **判断所需数据源** | 账户收支流水（入账金额、入账时间、出账金额、出账时间、出账对象） |
| **关键数据特征** | ① 资金入账后平均停留时间<2小时即全部转出；② 入账金额与出账金额高度接近（差额<5%，仅扣除手续费）；③ 入账来源与出账去向完全不同（不是退款、不是转存）；④ 该模式在30天内重复出现≥5次；⑤ 账户日常余额极低（<100元），但流水金额大（单日>10万元） |
| **判定阈值** | ①+②+④同时满足，判定为高风险 |
| **与其他类型区分** | 与"分拆交易"(2.2)的区别：快进快出的特征是资金在账户内停留时间极短，分拆交易的特征是金额被刻意拆分。一笔交易可能同时具有两种特征 |

#### 逻辑卡片 4.2：分散转移

| 字段 | 内容 |
|------|------|
| **原因名称** | 分散转移 |
| **所属分类** | 洗钱/资金异常流转 > 分散转移 |
| **业务定义** | 账户收到大额资金后，分散转入多个不同账户，形成"一对多"的扇出结构 |
| **判断所需数据源** | 账户转账记录（转出金额、转出对象、转出时间） |
| **关键数据特征** | ① 收到单笔大额转入后，24小时内向≥5个不同账户转出；② 转出金额合计占入账金额的90%以上；③ 接收方账户均为近期新开账户（开户时间<90天）；④ 各笔转出金额均低于大额交易报告阈值；⑤ 接收方账户之间无历史交易关系（非正常的商业网络） |
| **判定阈值** | ①+②+④同时满足，判定为高风险 |

#### 逻辑卡片 4.3：循环转账

| 字段 | 内容 |
|------|------|
| **原因名称** | 循环转账 |
| **所属分类** | 洗钱/资金异常流转 > 循环转账 |
| **业务定义** | 多个账户之间形成资金闭环（A→B→C→A），通过多次流转模糊资金来源 |
| **判断所需数据源** | 多个关联账户的完整转账链条 |
| **关键数据特征** | ① 资金在≥3个账户之间形成闭环路径；② 每次流转的金额高度接近（损耗<10%）；③ 流转周期呈现规律性（如每周一次）；④ 参与循环的账户开户时间集中（同一时期批量开户）；⑤ 参与循环的账户除相互转账外，几乎无其他交易行为 |
| **判定阈值** | 检测到闭环路径（①满足）且②满足，直接判定为高风险 |

#### 逻辑卡片 4.4：跨境异常转移

| 字段 | 内容 |
|------|------|
| **原因名称** | 跨境异常转移 |
| **所属分类** | 洗钱/资金异常流转 > 跨境异常转移 |
| **业务定义** | 资金通过复杂路径最终流向境外，且缺乏合理的商业背景 |
| **判断所需数据源** | 跨境交易记录（金额、币种、收款国家/地区、交易备注）、用户业务背景 |
| **关键数据特征** | ① 个人账户频繁进行跨境汇款（月均≥3次），但该用户无外贸、留学等合理背景；② 跨境汇款的目的地为FATF认定的高风险国家/地区；③ 跨境汇款的备注信息模糊或反复使用相同措辞；④ 汇款前账户刚从多个不同来源收到资金（组合了分散转移+跨境转移） |
| **判定阈值** | 满足①+②判定为高风险 |

### 2.5 团伙欺诈

#### 逻辑卡片 5.1：中介代办欺诈

| 字段 | 内容 |
|------|------|
| **原因名称** | 中介代办欺诈 |
| **所属分类** | 团伙欺诈 > 中介代办欺诈 |
| **业务定义** | 中介机构收集多个真人身份信息，统一包装材料、批量提交贷款申请，收取服务费 |
| **判断所需数据源** | 批量申请的设备信息、IP信息、申请时间分布、材料文本相似度 |
| **关键数据特征** | ① 多个不同身份的申请使用同一设备ID或同一Wi-Fi网络MAC地址；② 多份申请的材料在格式、字体、排版、用词上高度相似（文本相似度>80%）；③ 多个申请的提交时间高度集中（如同一天内提交≥5份）；④ 多个申请人的联系人列表存在大量重叠（≥3个共同联系人）；⑤ 多个申请人的收货地址或居住地址相同或相邻 |
| **判定阈值** | ①+③同时满足，或②+④同时满足，判定为高风险团伙 |
| **与其他类型区分** | 中介代办与"盗用身份"(1.1)的区别：中介代办通常获得了身份主人的配合（虽然身份主人可能不了解后果），盗用身份是完全未经授权。中介代办的特征是"批量化、模板化"，盗用身份的特征是"单点、隐蔽" |

#### 逻辑卡片 5.2：刷单团伙

| 字段 | 内容 |
|------|------|
| **原因名称** | 刷单团伙 |
| **所属分类** | 团伙欺诈 > 刷单团伙 |
| **业务定义** | 多个账户协同配合进行虚假交易，共同套取资金或获取平台补贴 |
| **判断所需数据源** | 多个账户的交易网络、设备关联信息、资金流向 |
| **关键数据特征** | ① 一组账户之间形成密集的双向交易网络（团伙内部互相交易）；② 团伙内账户的注册时间集中在同一时期；③ 团伙内多个账户使用相同设备或IP地址段；④ 团伙内资金最终汇聚到少数"核心账户"；⑤ 团伙内交易的评价/备注内容高度雷同 |
| **判定阈值** | 检测到≥3个账户满足①+③，判定为团伙行为 |

#### 逻辑卡片 5.3：内外勾结

| 字段 | 内容 |
|------|------|
| **原因名称** | 内外勾结 |
| **所属分类** | 团伙欺诈 > 内外勾结 |
| **业务定义** | 金融机构内部员工利用职务便利，配合外部人员绕过风控规则实施欺诈 |
| **判断所需数据源** | 审批操作日志（审批人、审批时间、审批结果）、审批人与申请人的关联分析 |
| **关键数据特征** | ① 某审批人的通过率显著高于同岗位平均值（偏差>2个标准差）；② 某审批人通过的案件中，后续违约率显著高于平均水平；③ 某审批人频繁加急处理特定区域或特定中介渠道的申请；④ 审批人与申请人存在可追溯的社交关联（如共同通讯记录、相同地址） |
| **判定阈值** | ①+②同时满足，触发内部审查；④满足则升级为高风险 |
