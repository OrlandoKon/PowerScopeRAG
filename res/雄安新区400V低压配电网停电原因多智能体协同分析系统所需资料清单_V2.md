# 雄安新区400V低压配电网停电原因分析知识库所需资料清单

**版本**：V2.0

**日期**：2026年7月13日

## 一、总体说明

本清单列明雄安新区400V低压配电网停电原因分析知识库建设所需的数据基础资料，以及后续知识库检索与问答能力评测过程中建议国网省公司协助完成的专业审核事项。相关资料将用于建设标准规范知识库、历史案例库和可信评测基准，支撑停电事件的专业知识检索、相似案例匹配、候选原因分析、依据追溯和知识库效果评价。

所提供内容应尽量贴合雄安新区400V低压配电网实际业务，重点覆盖低压台区、低压配电、停电分析、故障处置和运行维护等场景。资料可按有关要求进行脱敏，但应尽量保留影响专业判断的设备、时间、现象、量测、告警、处置和结论信息。

### 工作内容总览

本清单按项目进度分为“现阶段资料准备”和“后续评测协同”两个阶段：前者为当前需要准备的资料，后者为知识库建成后开展评测和持续迭代时需要协助的工作。

| 序号 | 工作阶段 | 资料或配合事项 | 主要用途 | 建议形式 |
|---|---|---|---|---|
| 1 | 现阶段资料准备 | 标准规范与专业资料 | 建设标准与专业知识库，提供权威依据和业务口径 | PDF、DOCX、XLSX等原始文件及资料目录 |
| 2 | 现阶段资料准备 | 结构化历史停电案例 | 建设历史案例库，支持相似案例检索和原因分析 | XLSX、CSV或JSONL，附件单独归档 |
| 3 | 现阶段资料准备 | 一线专家知识 | 沉淀故障研判经验、排查思路和易混淆情况 | DOCX、XLSX、Markdown或访谈纪要 |
| 4 | 现阶段资料准备 | 必要资料属性 | 支持元数据过滤、适用性判断和结果追溯 | 元数据清单或原系统已有字段 |

### 2.2 结构化历史停电案例

#### 2.2.1 资料说明

收集真实历史停电案例及其现场处置记录、最终原因判定和专家复盘结论，建设独立的历史案例库，补齐“停电现象—现场核查—处置恢复—原因判定—经验复盘”的真实业务知识链条。相关资料用于检索相似事件及其处置经验，并与标准规范提供的技术依据相互补充。该部分建设效果后续可通过相似案例召回率、原因类别覆盖率和专家评审一致性进行验证。

#### 2.2.2 内容要求

- 记录案例编号、发生时间、台区编号（可脱敏）、停电现象与影响范围，以及停电前的量测、告警和保护动作等数据特征；
- 完整保留现场核查情况、关键处置步骤、恢复送电过程及恢复后的验证结果；
- 明确最终停电原因、原因判定依据和专家复盘结论，并将停电前可见信息与事后确认结论分开保存。

#### 2.2.3 格式要求

- 建议采用XLSX、CSV或JSONL格式，一行或一个JSON对象对应一个案例；
- 案例编号应唯一，现场照片、工单、告警清单等附件可通过案例编号关联；
- 缺失信息可留空或标注“待确认”，不应根据经验补写。

#### 2.2.4 参考示例

以下内容仅作为单个案例的结构和字段格式参考，不代表真实事件：

| 字段 | 示例内容 |
|---|---|
| **案例编号** | CASE-XA-2025-001 |
| **发生时间** | 2025-07-18 14:35:00 |
| **台区编号** | XA-TQ-001（已脱敏） |
| **停电现象与影响范围** | 低压总开关跳闸，全台区用户失电，上级电源及相邻台区供电正常 |
| **停电前数据特征描述** | 停电前最大相电流持续升高并超过总开关长延时保护整定值，三相负荷不平衡 |
| **保护及告警记录** | 14:35记录低压总开关过负荷长延时保护动作，无短路保护动作记录 |
| **现场核查情况** | 配变外观及温度正常，低压线路未发现短路、放电和明显绝缘损伤，核查结果与过负荷特征一致 |
| **现场处置记录** | 14:42核对保护记录，14:50检查低压线路，15:05转移部分负荷并复测三相电流 |
| **恢复送电与验证** | 15:18合闸恢复送电；持续观察30分钟，三相电流低于保护整定值且未再次跳闸 |
| **停电原因最终判定结果** | 三相负荷不平衡且最大相电流持续越限，导致低压总开关过负荷保护动作 |
| **原因判定依据** | 停电前最大相电流、保护动作记录、现场排除短路故障的核查结果，以及减载后试送成功情况相互印证 |
| **专家复盘结论** | 不能仅依据配变总负载率判断是否过负荷；应综合最大相电流、持续时间、保护整定值和现场核查结果进行判定 |

### 2.3 一线专家知识

#### 2.3.1 资料说明

系统沉淀一线专家在长期运行维护和故障处置中形成的研判经验与专业知识，用于补充标准条文和历史案例难以完整表达的隐性知识，提升系统对复杂、相似和信息不完整场景的分析能力。

#### 2.3.2 内容要求

- 提供典型故障判断经验、常见原因识别方法和实际排查思路；
- 重点说明易混淆情况、关键区分特征及数据不完整时的研判经验；
- 补充雄安新区实际运行中的特殊设备、负荷和业务场景，并说明经验的适用条件。

#### 2.3.3 格式要求

- 格式不限，可直接提供现有培训材料、案例复盘、工作总结、文字说明或访谈纪要；
- 专家可按日常工作习惯自然描述，不需要填写技术字段表，由项目组负责整理和结构化；
- 项目组整理后再请相关专家核对，存在不同意见时分别保留。

#### 2.3.4 参考示例

以下内容仅作为专家自然描述经验的形式参考，不要求逐项填写：

> **全台区停电的初步排查经验**
>
> 遇到台区全部用户同时失电时，通常先查看同一上级电源下其他台区是否也停电，以判断故障是否由上级电源传导。如果上级电源正常且低压总开关发生保护动作，再结合停电前的三相电流、保护动作类型和现场设备状态进行排查。
>
> 配变总负载率不高时，也不能直接排除低压线路过载，因为三相负荷不平衡可能导致某一相电流超过线路允许载流量。若现场未发现设备损坏，减载后能够恢复送电，可进一步结合保护记录判断是否为过负荷保护动作；若试送失败或存在焦糊、绝缘异常等现象，则应继续检查设备本体和线路故障。
>
> 上述经验需要结合实际量测、保护记录和现场检查使用，证据不足时不能仅凭单一现象确定最终原因。

项目组可将上述自然语言经验整理为适用场景、关键现象、研判要点、易混淆情况和排查建议等结构化内容，再交由专家确认。

### 2.4 必要资料属性

#### 2.4.1 资料说明

为支持精准检索、元数据过滤、证据适用性判断和结果追溯，建议在条件允许时为标准资料、历史案例和专家知识同步保留必要属性。相关属性以省公司现有系统和资料中的真实字段为基础，可逐步补充完善。

#### 2.4.2 内容要求

建议至少保留以下属性：

- **当前有效状态**：现行有效、已废止、试行、待确认等；
- **适用范围**：适用地区、组织、系统或业务边界；
- **电压等级**：如400V、10kV或其他相关等级；
- **设备对象**：如配电变压器、低压开关、低压电缆、保护装置等；
- **故障类型**：沿用现有资料或业务系统中的故障类型字段；
- **停电原因类别**：沿用现有业务系统中的原因类别及编码；
- **适用业务场景**：如运行监测、停电研判、现场排查、故障处置、复盘分析等；
- **来源与确认信息**：资料版本、更新时间、审核信息和确认状态。

原始资料暂不具备某项属性时，可保留空值并标注待补充，不建议根据文件名或非权威描述自行推断。

#### 2.4.3 格式要求

- 文档类资料在资料目录中增加属性列，案例和专家知识直接增加对应字段；
- 属性名称和取值应尽量统一，已有业务编码时同时保留编码与中文名称；
- 暂时缺失的属性可留空并标注待补充。

### 3.3 疑难与争议样本裁定

#### 3.3.1 资料说明

在后续系统评测与迭代阶段，项目组将汇总系统回答中表面合理但实际存在问题、自动指标难以判断、不同资料之间存在冲突或专家意见不一致的样本。届时建议由省公司专家对相关样本进行专业裁定，为评测结果解释和系统改进提供依据。

#### 3.3.2 内容要求

- 判断系统答案是正确、部分正确还是错误，并说明具体原因；
- 区分问题表述、检索证据、答案推理、资料冲突或评测标准等不同问题来源；
- 对资料冲突或证据关系不明确的样本给出采用口径；信息不足时列明需要补充的资料。

#### 3.3.3 格式要求

- 采用XLSX争议样本裁定表，一行对应一个争议样本；
- 核心内容包括争议问题、系统回答、相关证据、专家裁定和处理建议，项目组负责整理具体表格。

#### 3.3.4 参考示例

以下内容仅作为专家裁定意见的表达形式参考：

| 项目 | 内容 |
|---|---|
| 争议问题 | 某台区配变总负载率未超过额定值，是否可以排除低压线路过载？ |
| 系统回答 | 可以排除，因为配变总负载率未超过100%。 |
| 专家裁定 | 不能仅依据配变总负载率排除低压线路过载。三相负荷不平衡时，单相电流仍可能超过线路允许载流量，应进一步比较最大相电流与线路允许载流量。 |
| 处理建议 | 修订该题标准答案，并将最大相电流和线路允许载流量列为必要判断依据。 |
