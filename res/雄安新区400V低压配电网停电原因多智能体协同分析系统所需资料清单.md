# 雄安新区400V低压配电网停电原因多智能体协同分析系统所需资料清单

**版本**：V1.0
**日期**：2026年5月20日

---

## 一、总体说明

本清单列明了雄安新区400V低压配电网停电原因智能分析系统知识库建设所需的四类基础资料，请国网河北省电力有限公司相关部门按要求提供，以支撑系统的停电原因分类体系构建、智能判断逻辑设计、专家经验沉淀及技术标准对标工作。

雄安新区电网具有以下显著特征：**全地下电缆化**、**综合管廊敷设**、**在建工程密集**、**新型负荷集中**、**高度智能化**，所提供资料应充分体现场景差异性，避免套用通用台区的经验。

### 资料清单总览

| 序号 | 资料类别 | 资料用途 |
|------|----------|----------|
| 1 | 停电原因分类树 | 构建停电原因分类体系，作为系统判断的顶层框架 |
| 2 | 判断逻辑清单 | 明确每类停电原因的数据特征与判断规则，作为系统推理依据 |
| 3 | 专家经验库 | 沉淀一线运维专家的诊断经验，补充系统难以自动化的隐性知识 |
| 4 | 技术资料库 | 提供标准规范、运维规程、历史报告等文档，作为系统知识检索的基础语料 |

## 二、资料一：400V低压配电网停电原因分类树

### 2.1 资料说明

构建一套完整、系统、可落地的400V低压配电网停电原因分类体系，明确各类停电原因的层级关系，为后续智能体推理设计和知识库构建提供顶层框架。

### 2.2 内容要求

- 涵盖雄安新区400V低压配电网的全部主要停电原因，包括大类（不少于4类）和末端子类（不少于20个末端类别）；
- 每个末端类别应具备**互斥性**（同一事件归入唯一类别）和**可操作性**（可对应具体数据特征进行判断）；
- 应充分体现雄安新区场景特殊性，明确标注与通用台区场景的差异项；
- 建议由配网运维、台区管理、用户服务等方向的一线专家共同梳理。

### 2.3 格式要求

请以树状结构提供，编号方式统一，示例格式参见第2.4节。

### 2.4 参考示例

## 三、资料二：判断逻辑清单

### 3.1 资料说明

针对分类树中每一个末端停电原因子类，提供结构化的判断逻辑卡片，作为系统自动化推理的核心依据。

### 3.2 内容要求

- 覆盖分类树全部末端类别，每个类别对应一张逻辑卡片；
- 每张卡片须包含：原因名称、所属分类、业务定义、判断所需数据源、关键数据特征、判定阈值、与相似原因的区分方法、历史典型案例编号；
- 判定阈值应明确具体数值（如温度、电流、负载率等），避免模糊描述；
- 数据源须注明对应系统名称（如TTU、SCADA、OMS、营销系统等）；
- 应充分体现雄安新区场景特殊性，如管廊监控、充电桩管理系统等雄安特有数据源。

### 3.3 格式要求

请以表格形式逐卡片提供，字段说明参见第3.4节示例。

### 3.4 参考示例

以下为逻辑卡片 1.1.1 的示例格式：

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变过热/绕组烧损 |
| **所属分类** | 设备类原因 > 配变故障（1.1.1） |
| **业务定义** | 配电变压器因长期过负荷、散热不良或绝缘老化导致绕组温升超限并烧损，引发全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：配变油温/绕组温度、三相电流、有功功率；用电信息采集系统：台区下所有用户停电时刻；配网自动化系统（SCADA）：配变高压侧开关状态及保护动作类型；故障抢修系统：现场勘查记录 |
| **关键数据特征** | ① 停电前1小时内配变油温持续上升，停电时刻触发温度告警（油浸式变压器油温>85°C，干式变压器绕组温度>130°C）；② 停电前配变三相负荷电流超过额定值（负载率>100%，持续时间>30分钟）；③ 台区全部用户同时失电，停电时刻与配变高压侧开关跳闸时刻吻合；④ 重合闸不成功（合闸后立即再次跳闸）；⑤ 现场检查发现配变有焦糊气味、绝缘油颜色变深或喷油现象 |
| **雄安补充说明** | 雄安新区夏季制冷和冬季电采暖负荷集中，叠加充电桩负荷，配变过负荷风险较高；TTU全覆盖使得温度曲线数据完整，过热判断置信度高 |
| **判定阈值** | 满足①+③+④，判定为高置信度；满足①+②+③，判定为中置信度，须现场确认 |
| **与相似原因区分** | 与"台区总过负荷跳闸"(2.1.1)的区别：过负荷跳闸时配变本身无损坏，减负后可复位断路器恢复送电；配变烧损则无法送电，需更换设备。与"10kV馈线故障传导"(5.1.1)的区别：配变故障时，同馈线其他台区用户不停电 |
| **历史典型案例编号** | XA-DEV-001（雄安某商务区台区夏季充电桩与中央空调负荷叠加致配变烧损） |

## 四、资料三：专家经验库

### 4.1 资料说明

收集雄安新区400V配电运维一线专家的诊断经验，包括难以从数据直接推断的隐性知识、特殊场景下的处置规则以及历史典型故障案例，作为系统知识库的重要补充，格式不限，文本形式最佳。

### 4.2 内容要求

请按以下三个维度提供资料：

**（1）典型故障案例**

每个案例须包含：案例编号、发生时间、台区编号（可脱敏）、停电原因最终判定结果、停电前数据特征描述、现场核查情况、恢复送电过程、经验教训。建议提供不少于30个典型案例，应覆盖各主要停电原因类别。

**（2）经验规则**

专家在长期运维中总结的判断规律，包括但不限于：
- 季节性规律（如夏季充电桩叠加空调负荷高峰的典型特征）；
- 组合特征规则（如"重合闸不成功+全台区停电+TTU无温度告警"指向10kV侧故障）；
- 雄安特有场景的判断技巧（管廊渗水、施工破坏的早期预警信号等）。

**（3）排查流程说明**

一线班组在实际接警后的标准排查步骤与经验性优先级，包括与系统自动分析结果的人工核验要点。
