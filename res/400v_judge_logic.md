# 400V低压配电网停电原因判断逻辑清单（雄安新区场景）

> **场景说明**：本文档面向雄安新区400V低压配电网，基于该场景的特殊性（全地下电缆化、综合管廊敷设、充电桩/分布式光伏高密度接入、在建工程密集、配网自动化全覆盖）对通用台区的判断逻辑进行针对性修订。已删除架空线、电杆、树木相关卡片，新增管廊、充电桩、光伏等雄安特有场景的逻辑卡片。
>
> 案例编号格式：`XA-` 前缀表示雄安新区场景案例。

---

## 一、设备类原因

### 1.1 配变故障

#### 逻辑卡片 1.1.1：配变过热/绕组烧损

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变过热/绕组烧损 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配电变压器因长期过负荷、散热不良或绝缘老化导致绕组温升超限并烧损，引发全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：配变油温/绕组温度、三相电流、有功功率；用电信息采集系统：台区下所有用户停电时刻；配网自动化系统：配变高压侧开关状态及保护动作类型；故障抢修系统：现场勘查记录 |
| **关键数据特征** | ① 停电前1小时内配变油温持续上升，停电时刻配变温度告警（油浸式变压器油温>85°C，干式变压器绕组温度>130°C）；② 停电前配变三相负荷电流超过额定电流（负载率>100%，持续时间>30分钟）；③ 台区下全部用户同时失电，停电时刻与配变高压侧开关跳闸时刻吻合；④ 重合闸不成功（合闸后立即再次跳闸）；⑤ 现场检查发现配变有焦糊气味、绝缘油颜色变深/喷油现象 |
| **雄安补充说明** | 雄安新区夏季制冷和冬季电采暖负荷集中，叠加大量充电桩负荷，配变过负荷风险较高；TTU全覆盖使得温度曲线数据完整，过热判断置信度高 |
| **判定阈值** | 满足①+③+④，判定为高置信度；满足①+②+③，判定为中置信度，需现场确认 |
| **与其他原因区分** | 与"台区总过负荷跳闸"(2.1.1)的区别：过负荷跳闸时配变本身无损坏，减负后可复位断路器恢复送电；配变烧损则无法送电，需更换设备。与"10kV馈线故障传导"(5.1.1)的区别：配变故障时，同馈线其他台区用户不停电 |
| **历史典型案例编号** | XA-DEV-001（雄安某商务区台区夏季充电桩与中央空调负荷叠加致配变烧损） |

#### 逻辑卡片 1.1.2：配变绝缘击穿

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变绝缘击穿 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配变内部绝缘材料老化或受潮，在正常运行电压下发生绝缘击穿，引发匝间短路或高低压侧串联，导致全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：三相电压、三相电流、零序电流；配网自动化系统：保护动作类型；设备台账（PMS）：配变投运年限、历次预试记录；气象数据：近期是否有强降雨（潮湿环境） |
| **关键数据特征** | ① 停电时刻零序电流突变，幅值异常（>5A，正常运行时接近0）；② 保护动作类型为"差动保护"或"接地保护"；③ 配变投运年限>15年，且近2年未进行预防性试验；④ 停电前1~7天内曾有强降雨（绝缘受潮诱因）；⑤ 重合闸不成功 |
| **雄安补充说明** | 雄安新区配变多为建设期新设备，老化因素相对较少；更需关注设备安装调试阶段的质量问题（投运初期绝缘不合格）和地下设备间受潮（箱变基础积水） |
| **判定阈值** | 满足①+②判定为高置信度；满足③+④+⑤判定为中置信度，需绝缘电阻测试确认 |
| **与其他原因区分** | 与"配变过热/绕组烧损"(1.1.1)的区别：绝缘击穿是突发性跳闸，无明显温升前期特征。与"雷击感应过电压"(3.1.1)的区别：雷击有明确雷暴天气和冲击电流波形 |
| **历史典型案例编号** | XA-DEV-002（新建箱变地基积水导致绝缘受潮击穿） |

#### 逻辑卡片 1.1.3：配变分接头接触不良

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变分接头接触不良 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配变无载调压分接头因接触面氧化或螺栓松动，导致接触电阻增大，引发电压异常 |
| **判断所需数据源** | 配变监测终端（TTU）：低压侧三相输出电压；用电信息采集系统：台区用户电压合格率；设备台账：分接头档位及最近调整记录 |
| **关键数据特征** | ① 台区低压侧三相电压长期偏低（电压合格率<95%，<198V），且三相之间电压偏差显著；② 配变实测变比与铭牌变比偏差>3%；③ 设备台账显示分接头超过2年未调整 |
| **雄安补充说明** | 雄安新区楼宇密集、用电负荷增长快，分接头档位需定期根据实际负荷调整；雄安智慧城市平台可推送电压合格率预警，辅助提前发现此类问题 |
| **判定阈值** | 满足①+②+③判定为中置信度，需停电后测量接触电阻（>1000μΩ为异常）确认 |
| **与其他原因区分** | 此类故障通常不直接导致停电，而是引发长期低电压，需与"末端低电压触发用户设备保护跳闸"(2.3.1)联合判断 |
| **历史典型案例编号** | XA-DEV-003（雄安某住宅小区台区分接头档位与实际负荷不匹配，末端长期低电压） |

### 1.2 低压电缆故障

> **雄安说明**：雄安新区城区禁止架空线，低压网络全部为地下电缆，本节不含架空线相关故障，全部为地下电缆场景。

#### 逻辑卡片 1.2.1：低压电缆绝缘老化/热效应击穿

| 字段 | 内容 |
|------|------|
| **原因名称** | 低压电缆绝缘老化/热效应击穿 |
| **所属分类** | 设备类原因 > 低压电缆故障 |
| **业务定义** | 地下低压电缆因长期过载发热或绝缘老化，导致绝缘层热效应击穿，引发接地或相间短路，造成该电缆所带用户停电 |
| **判断所需数据源** | 配变监测终端（TTU）：停电时刻三相电流及零序电流；用电信息采集系统：停电用户分布（局部停电特征）；设备台账（PMS）：电缆铺设年限及历次测试记录；综合管廊监控系统：管廊内电缆通道温度（若已部署分布式测温） |
| **关键数据特征** | ① 停电范围局限于该电缆所带的用户（局部停电），其他分支用户不停电；② TTU记录显示配变二次侧零序电流突变（>正常值3倍），对应相电压下降；③ 重合闸不成功（短路点持续存在）；④ 设备台账显示该段电缆载流量长期接近或超过额定值（结合历史负荷数据）；⑤ 综合管廊测温数据显示该段电缆通道温度异常偏高（>管廊设计温度上限） |
| **判定阈值** | 满足①+②+③判定为高置信度；满足①+④+⑤判定为中置信度，需电缆测试仪故障定位确认 |
| **与其他原因区分** | 与"综合管廊内电缆受损"(1.2.3)的区别：热效应击穿是电缆自身长期过热劣化，无外力介入；管廊受损是外部因素（渗水/机械力）引发。判断依据是管廊环境监控数据和施工记录 |
| **历史典型案例编号** | XA-LINE-001（雄安某商业街区地下电缆长期超载运行，绝缘热效应击穿） |

#### 逻辑卡片 1.2.2：低压电缆接头过热/氧化腐蚀

| 字段 | 内容 |
|------|------|
| **原因名称** | 低压电缆接头过热/氧化腐蚀 |
| **所属分类** | 设备类原因 > 低压电缆故障 |
| **业务定义** | 低压电缆压接接头或中间接线盒因施工质量不达标、接触面氧化腐蚀，接触电阻升高，引发局部过热乃至断路，导致下游用户停电 |
| **判断所需数据源** | 配变监测终端（TTU）：下游相电压趋势（接头接触不良时电压缓慢下降）；用电信息采集系统：下游用户电压合格率及停电时刻；综合管廊巡检记录：接头温度（红外测温）；设备台账（PMS）：接头施工记录、质量验收报告 |
| **关键数据特征** | ① 停电前该相下游用户电压缓慢下降（非突变，区别于短路）；② 综合管廊巡检红外测温数据显示该接头热点温度差Δt>35K（严重缺陷）；③ 停电范围为该接头下游所有用户（局部停电）；④ 设备台账显示该接头为建设期施工接头，施工工艺验收记录存在质量疑点 |
| **雄安补充说明** | 雄安新区大量接头为新建期施工接头，施工质量参差不齐；综合管廊提供了便利的接头巡检通道，管廊内定期红外测温可有效发现此类隐患 |
| **判定阈值** | 满足②+③判定为高置信度；满足①+③+④判定为中置信度，需停电后用接触电阻仪（>200μΩ为异常）确认 |
| **与其他原因区分** | 与"低压电缆绝缘老化击穿"(1.2.1)的区别：接头腐蚀有电压缓慢下降的前期特征，电缆绝缘击穿是突发性跳闸。与"综合管廊内电缆受损"(1.2.3)的区别：接头腐蚀是渐进老化，无外部突发事件触发 |
| **历史典型案例编号** | XA-LINE-002（新建楼宇低压电缆接头施工不规范，运行1年后过热断路） |

#### 逻辑卡片 1.2.3：综合管廊内电缆受损

| 字段 | 内容 |
|------|------|
| **原因名称** | 综合管廊内电缆受损（渗水/高温/机械损伤） |
| **所属分类** | 设备类原因 > 低压电缆故障 |
| **业务定义** | 敷设于综合管廊内的低压电缆，因管廊渗水（雨季）、管廊通风故障导致局部高温，或管廊内其他管线施工/维修的机械损伤，引发电缆故障停电 |
| **判断所需数据源** | 综合管廊监控系统：管廊内温度、湿度、积水告警、氧气/有毒气体告警；配变监测终端（TTU）：停电时刻电气量特征；施工工单记录：管廊内近期是否有其他专业施工；气象数据：近期降雨量（判断渗水诱因） |
| **关键数据特征** | ① 综合管廊监控系统显示，停电时刻前后该管廊段存在渗水告警（积水深度>预设阈值，如10cm）或温度超限告警（>设计温度上限）；② TTU记录显示该段电缆某相电流异常（渗水短路时零序电流突变，高温击穿时电流增大后归零）；③ 停电前管廊内有其他专业（供水/燃气/通信）的施工工单，且施工段与停电电缆段位置重合；④ 停电范围精确对应该管廊段所带的低压用户 |
| **判定阈值** | 满足①+②+④判定为高置信度（渗水/高温原因）；满足③+②+④判定为高置信度（施工损伤原因，见3.2.2） |
| **与其他原因区分** | 三种子原因（渗水/高温/施工损伤）均归入此卡片，但结论描述有差异：渗水引发的归为"自然灾害间接引发"，施工损伤的归为"外力破坏"（对应3.2.2）。判断依据是管廊监控数据和施工工单 |
| **历史典型案例编号** | XA-LINE-003（强降雨后管廊局部渗水，积水浸泡低压电缆接线盒导致短路） |

### 1.3 低压开关及保护装置故障

#### 逻辑卡片 1.3.2：漏电保护器误动作

| 字段 | 内容 |
|------|------|
| **原因名称** | 漏电保护器误动作 |
| **所属分类** | 设备类原因 > 低压开关及保护装置故障 |
| **业务定义** | 漏电保护器（RCD）因元件老化、动作阈值漂移、谐波干扰或受潮，在无真实漏电故障的情况下发生误动作跳闸 |
| **判断所需数据源** | 配变监测终端（TTU）：停电时刻零序基波电流值；用电信息采集系统：停电范围；充电桩管理系统：停电时刻台区充电桩总功率及谐波数据；设备台账：漏电保护器型号、安装时间 |
| **关键数据特征** | ① 停电时刻TTU记录的零序基波电流低于漏电保护器额定动作电流（如<30mA），但存在明显谐波分量（充电桩/逆变器谐波电流流过零序互感器引发误判）；② 手动复位后能够成功送电，后续数小时内无异常；③ 停电前台区充电桩使用量处于高峰（充电桩谐波是雄安场景下误动的常见诱因）；④ 漏电保护器投运年限>8年，或近6个月已发生≥2次无法解释的误动 |
| **雄安补充说明** | 雄安新区充电桩密度高，充电桩PFC变换器产生的谐波电流可通过零序互感器引发漏电保护器误动，是区别于传统台区的特有原因；需关注谐波数据与误动的相关性 |
| **判定阈值** | 满足①+②判定为高置信度（误动作）；满足②+③判定为中置信度，需分析谐波数据 |
| **与其他原因区分** | 与"用户内部设备短路/接地故障"(4.1.1)的区别：用户侧真实故障时，零序基波电流真实超标，且复位后再次跳闸；谐波误动时，零序基波正常且复位后不再跳闸。与"充电桩谐波污染"(2.2.1)的区别：谐波误动的后果是漏保跳闸，谐波污染是导致这一结果的原因，两者为因果关系 |
| **历史典型案例编号** | XA-PROT-001（雄安某住宅小区充电桩高峰期谐波触发总漏保误动） |

## 二、负荷类原因

### 2.1 过负荷保护动作

#### 逻辑卡片 2.1.1：台区总过负荷跳闸

| 字段 | 内容 |
|------|------|
| **原因名称** | 台区总过负荷跳闸 |
| **所属分类** | 负荷类原因 > 过负荷保护动作 |
| **业务定义** | 台区总用电负荷持续超过配变额定容量，总断路器因过流保护动作跳闸，导致台区全部用户停电 |
| **判断所需数据源** | 配变监测终端（TTU）：三相电流、有功功率、负载率；充电桩管理系统：停电前台区充电桩总功率；气象数据：气温（冷热负荷高峰）；营销业务系统：台区近期是否有大容量用户新接入 |
| **关键数据特征** | ① 停电前15分钟内，配变负载率持续>100%（三相电流均超额定电流）；② 保护动作类型为"过流保护"；③ 台区下全部用户同时停电；④ 充电桩管理系统显示停电前充电桩总功率处于高峰（占台区总负荷比例>30%）；⑤ 降负荷（如暂停部分充电桩）后可成功合闸送电 |
| **雄安补充说明** | 雄安新区充电桩高密度部署是过负荷的重要推手，需将充电桩管理系统的实时功率数据纳入分析；另外政务楼宇和数据中心的高负荷特性也需关注 |
| **判定阈值** | 满足①+②+③+⑤判定为高置信度 |
| **与其他原因区分** | 与"配变过热/绕组烧损"(1.1.1)的区别：过负荷跳闸后合闸成功，配变烧损后合闸不成功。与"10kV馈线故障传导"(5.1.1)的区别：台区过负荷时，仅本台区停电，同馈线其他台区正常 |
| **历史典型案例编号** | XA-LOAD-001（雄安某居住区台区夏季充电桩与中央空调同时满载，负载率达185%跳闸） |

#### 逻辑卡片 2.1.2：单相过负荷（三相严重不平衡）

| 字段 | 内容 |
|------|------|
| **原因名称** | 单相过负荷（三相严重不平衡） |

| **雄安补充说明** | 雄安新区充电桩密度高，充电桩绝缘故障是用户侧故障的重要来源；充电桩管理系统的故障码可辅助快速定位故障设备 |
| **判定阈值** | 满足①+②+④判定为高置信度；满足①+②+⑤判定为中置信度，需现场确认 |
| **与其他原因区分** | 与"漏电保护器误动作"(1.3.2)的区别：用户侧真实故障时零序电流真实超标，复位后再次跳闸；误动作时零序正常且复位后可持续供电。与"充电桩谐波污染"(2.2.1)的区别：充电桩故障是绝缘故障（有真实漏电），谐波误动是波形问题（无真实漏电）|
| **历史典型案例编号** | XA-USER-001（雄安某停车楼用户自有充电桩充电枪绝缘损坏，接地故障引发跳闸） |
