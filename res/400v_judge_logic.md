# 400V低压配电网停电原因判断逻辑清单

> 本文档基于《400V低压配电网停电原因分类树》，为每种停电原因提供结构化的判断逻辑卡片，定义所需数据源、关键数据特征与阈值、与其他原因的区分要点，作为智能体设计和提示词工程的直接输入。

---

## 一、设备类原因

### 1.1 配变故障

#### 逻辑卡片 1.1.1：配变过热/绕组烧损

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变过热/绕组烧损 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配电变压器因长期过负荷、散热不良或绝缘老化导致绕组温升超限并烧损，引发全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：配变油温/绕组温度、三相电流、有功功率；用电信息采集系统：台区下所有用户停电时刻；配网自动化系统：配变高压侧开关状态；故障抢修系统：现场勘查记录 |
| **关键数据特征** | ① 停电前1小时内配变油温持续上升，停电时刻配变温度告警（油浸式变压器油温>85°C，干式变压器绕组温度>130°C）；② 停电前配变三相负荷电流超过额定电流（负载率>100%，持续时间>30分钟）；③ 台区下全部用户同时失电，停电时刻与配变高压侧开关跳闸时刻吻合；④ 重合闸不成功（合闸后立即再次跳闸）；⑤ 现场检查发现配变有焦糊气味、绝缘油颜色变深/喷油现象 |
| **判定阈值** | 满足①+③+④，判定为高置信度；满足①+②+③，判定为中置信度，需现场确认 |
| **与其他原因区分** | 与"台区总过负荷跳闸"(2.1.1)的区别：过负荷跳闸时配变本身无损坏，减负后可复位断路器恢复送电；配变烧损则无法送电，需更换设备。判断依据是合闸能否成功。与"10kV馈线故障传导"(5.1.1)的区别：配变故障时，高压侧馈线其他台区用户不停电；传导停电时，同一10kV馈线下多个台区同时停电 |
| **历史典型案例编号** | CASE-DEV-001（夏季高温连续高负荷致配变烧损） |

---

#### 逻辑卡片 1.1.2：配变绝缘击穿

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变绝缘击穿 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配变内部绝缘材料老化或受潮，在正常运行电压下发生绝缘击穿，引发匝间短路或高低压侧串联，导致全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：三相电压、三相电流、零序电流；配网自动化系统：配变高压侧开关状态及保护动作类型；设备台账：配变投运年限、历次预试记录；气象数据：近期是否有强降雨/雷暴 |
| **关键数据特征** | ① 停电时刻零序电流（接地电流）突变，幅值异常（>5A，正常运行时接近0）；② 配变高压侧继电保护动作类型为"差动保护"或"接地保护"；③ 配变投运年限>15年，且近2年未进行预防性试验；④ 停电前1~7天内曾有强降雨（绝缘受潮诱因）；⑤ 重合闸不成功，或合闸后随即再次跳闸 |
| **判定阈值** | 满足①+②判定为高置信度；满足③+④+⑤判定为中置信度，需停电后绝缘电阻测试确认 |
| **与其他原因区分** | 与"配变过热/绕组烧损"(1.1.1)的区别：绝缘击穿通常是突发性跳闸（无明显预热过程），过热是渐进过程（温度曲线持续上升）。与"雷击"(3.1.1)的区别：雷击有雷暴天气背景且通常同一区域多点故障，绝缘击穿与天气相关性弱，或仅与雨水受潮相关 |
| **历史典型案例编号** | CASE-DEV-002（老旧配变遭遇梅雨季节绝缘受潮击穿） |

---

#### 逻辑卡片 1.1.3：配变分接头接触不良

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变分接头接触不良 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配变无载调压分接头因长期未调整、接触面氧化或螺栓松动，导致接触电阻增大，引发局部过热、电压异常或跳闸 |
| **判断所需数据源** | 配变监测终端（TTU）：低压侧三相输出电压；用电信息采集系统：台区下用户电压合格率；设备台账：分接头档位及最近调整记录 |
| **关键数据特征** | ① 台区低压侧三相电压长期偏低（电压合格率<95%，且低于标称220V的10%，即<198V），且电压偏差在三相之间差异显著；② 配变输出电压与输入电压之比（实测变比）与铭牌变比偏差>3%；③ 分接头所在档位与台区实际负荷不匹配（如档位过高或过低）；④ 设备台账显示分接头超过2年未调整 |
| **判定阈值** | 满足①+②+④判定为中置信度，需停电后测量分接头接触电阻（>1000μΩ为异常）确认 |
| **与其他原因区分** | 此类故障通常不直接导致停电，而是表现为持续低电压或局部电压异常，最终可能引发用户设备保护动作导致停电，需与"末端低电压触发用户设备保护跳闸"(2.3.1)联合判断 |
| **历史典型案例编号** | CASE-DEV-003（农网改造后分接头档位未调整致末端长期低电压） |

### 1.2 低压线路故障

#### 逻辑卡片 1.2.1：低压架空线断线/接地

| 字段 | 内容 |
|------|------|
| **原因名称** | 低压架空线断线/接地 |
| **所属分类** | 设备类原因 > 低压线路故障 |
| **业务定义** | 低压架空线因外力、老化或腐蚀发生断线或对地放电，导致该分支线路下所有用户停电，但同台区其他分支用户不受影响 |
| **判断所需数据源** | 用电信息采集系统：停电用户分布（哪些用户停电、哪些未停电）及停电时刻；配网自动化系统：低压分支线路故障指示器状态；配变监测终端（TTU）：配变二次侧三相电流（断线相电流骤降至0或接地相电流异常增大）；气象数据：停电时刻是否有强风、冰雪天气 |
| **关键数据特征** | ① 停电用户仅覆盖台区某一分支线路，其他分支线路用户不停电（部分停电特征）；② 低压故障指示器翻牌，指示故障位置在特定线段；③ 配变二次侧某相电流异常：断线时该相电流骤降为0，接地时该相电流增大且零序电流>正常值3倍；④ 停电时刻与恶劣天气（风速>8级、冰雪、雷暴）或工程施工时间重合 |
| **判定阈值** | 满足①+②判定为高置信度；满足①+③判定为中置信度，需现场巡线确认 |
| **与其他原因区分** | 与"配变故障"(1.1类)的区别：配变故障时台区全部用户停电，架空线故障仅影响该分支下用户。与"10kV馈线故障传导"(5.1.1)的区别：馈线故障时同一馈线下所有台区均停电，架空线故障仅影响本台区内局部用户 |
| **历史典型案例编号** | CASE-LINE-001（大风天气导致低压架空线断线，一个分支8户停电） |

#### 逻辑卡片 1.2.2：低压电缆绝缘击穿

| 字段 | 内容 |
|------|------|
| **原因名称** | 低压电缆绝缘击穿 |
| **所属分类** | 设备类原因 > 低压线路故障 |
| **业务定义** | 地埋低压电缆因绝缘老化、外力受压或受潮，发生绝缘击穿，引发接地或相间短路，导致该电缆所带用户停电 |
| **判断所需数据源** | 用电信息采集系统：停电用户分布；配变监测终端（TTU）：配变二次侧零序电流；配网GIS系统：低压电缆路径及敷设年限；施工工单记录：停电前附近是否有地面开挖工程 |
| **关键数据特征** | ① 停电范围局限于该电缆所带的用户（部分停电）；② 配变二次侧零序电流突变（>正常值3倍），且对应相电压下降；③ 合闸后立即再次跳闸（短路点仍存在，无法重合闸成功）；④ GIS系统显示故障区段电缆铺设年限>20年，或近期附近有施工记录；⑤ 停电前有强降雨天气（水浸诱发绝缘击穿） |
| **判定阈值** | 满足①+②+③判定为高置信度；满足①+④+⑤判定为中置信度，需停电后用电缆测试仪定位故障点 |
| **与其他原因区分** | 与"施工挖断地下电缆"(3.2.1)的区别：挖断电缆时施工工单或现场巡查有直接证据（地面开挖痕迹、施工人员报修）；绝缘击穿无明确外力证据，多为老化或受潮导致。判断依据是是否有施工现场证据 |
| **历史典型案例编号** | CASE-LINE-002（老旧居民区地下电缆老化受潮击穿） |

#### 逻辑卡片 1.2.3：接头/接线盒氧化腐蚀

| 字段 | 内容 |
|------|------|
| **原因名称** | 接头/接线盒氧化腐蚀 |
| **所属分类** | 设备类原因 > 低压线路故障 |
| **业务定义** | 低压线路的压接接头、T形接线盒或刀闸接头因长期氧化腐蚀，接触电阻异常升高，引发局部过热、打火或断路，导致下游用户停电 |
| **判断所需数据源** | 用电信息采集系统：下游用户电压趋势及停电时刻；配变监测终端（TTU）：三相电压（接头接触不良时，相应相电压从额定值缓慢下降）；配网运维巡视记录：上次巡视时是否发现接头发热；红外测温巡视数据：接头热点温度 |
| **关键数据特征** | ① 停电前该相下游用户电压长期偏低且呈缓慢下降趋势（不是突变，区别于短路）；② 红外测温数据显示该接头温度>环境温度+35°C（即热点温度差Δt>35K，为严重缺陷）；③ 停电范围为该接头下游所有用户（部分停电）；④ 运维巡视记录中，上次巡查时已发现该接头发热缺陷但未及时处理 |
| **判定阈值** | 满足②+③判定为高置信度；满足①+③+④判定为中置信度，需现场红外测温验证 |
| **与其他原因区分** | 与"低压架空线断线"(1.2.1)的区别：接头腐蚀通常有电压缓慢下降的前期特征，断线是突发停电无前期预兆。区别在于停电前电压曲线的变化模式 |
| **历史典型案例编号** | CASE-LINE-003（沿海高湿度地区接线盒严重氧化腐蚀） |

### 1.3 低压开关及保护装置故障

#### 逻辑卡片 1.3.2：漏电保护器误动作

| 字段 | 内容 |
|------|------|
| **原因名称** | 漏电保护器误动作 |
| **所属分类** | 设备类原因 > 低压开关及保护装置故障 |
| **业务定义** | 漏电保护器（RCD）因本身元件老化、动作阈值漂移或受潮，在无真实漏电故障的情况下发生误动作跳闸 |
| **判断所需数据源** | 用电信息采集系统：停电时刻及停电范围；配变监测终端（TTU）：停电时刻零序电流值（是否超过漏电保护器动作阈值，如30mA或300mA）；配网运维台账：漏电保护器型号、安装时间、历次动作记录；气象数据：是否有强降雨天气（湿度影响保护器性能） |
| **关键数据特征** | ① 停电时刻TTU记录的零序电流低于漏电保护器额定动作电流（如记录值<30mA但保护器动作），说明保护器灵敏度过高或误动；② 手动复位后能够成功送电，且后续数小时或数天内无异常（证明无真实漏电故障点）；③ 漏电保护器投运年限>8年，或近6个月内已发生≥2次无法解释的误动作；④ 停电前后有强降雨或高湿度天气（相对湿度>90%），保护器受潮导致灵敏度漂移 |
| **判定阈值** | 满足①+②判定为高置信度（误动作）；满足②+③+④判定为中置信度，需更换漏电保护器后观察 |
| **与其他原因区分** | 与"用户内部设备短路/接地故障"(4.1.1)的区别：用户侧故障时，零序电流真实超过保护器阈值，且复位后重新跳闸；误动作时，零序电流正常且复位后不再跳闸。判断依据是复位后是否能持续正常供电 |
| **历史典型案例编号** | CASE-PROT-001（梅雨季节总漏保受潮误动作，台区频繁停电） |

#### 逻辑卡片 1.3.3：熔断器熔断

| 字段 | 内容 |
|------|------|
| **原因名称** | 熔断器熔断 |
| **所属分类** | 设备类原因 > 低压开关及保护装置故障 |
| **业务定义** | 配变低压侧或分支线路的熔断器因通过短路电流、过载电流或自身老化而熔断，导致该分支用户停电 |
| **判断所需数据源** | 配变监测终端（TTU）：熔断时刻三相电流峰值；用电信息采集系统：停电用户范围及停电时刻；配网运维台账：熔丝规格及最近更换时间；现场勘查记录 |
| **关键数据特征** | ① 停电时刻TTU记录到电流突变峰值（>熔断器额定电流的6倍以上，短路情况），或长期超额定电流（>1.25倍，过载情况）；② 停电范围为熔断器保护段下游用户（部分停电）；③ 停电后现场检查发现熔断器熔体已断，更换相同规格熔丝后可正常送电 |
| **判定阈值** | 满足②+③判定为高置信度；满足①+②需进一步分析熔断原因（是短路引发还是过载引发） |
| **与其他原因区分** | 熔断器熔断本身是故障的结果，需进一步溯源：若是短路引发，需查找短路点（对应1.2类线路故障）；若是长期过载引发，对应2.1类负荷类原因；若无明显故障点、熔丝老化，则归入本卡片（装置自身故障） |
| **历史典型案例编号** | CASE-PROT-002（台区分支熔断器规格配置偏小，夏季高峰反复熔断） |

## 二、负荷类原因

### 2.1 过负荷保护动作

#### 逻辑卡片 2.1.1：台区总过负荷跳闸

| 字段 | 内容 |
|------|------|
| **原因名称** | 台区总过负荷跳闸 |
| **所属分类** | 负荷类原因 > 过负荷保护动作 |
| **业务定义** | 台区总用电负荷持续超过配变额定容量，总断路器（或配变高压侧熔断器）因过流保护动作跳闸，导致台区全部用户停电 |
| **判断所需数据源** | 配变监测终端（TTU）：配变三相电流、有功功率、视在功率、负载率；用电信息采集系统：台区下所有用户停电时刻及停电前用电量；气象数据：气温（高温是负荷高峰主要诱因）；营销业务系统：台区近期是否有大用户新接入 |
| **关键数据特征** | ① 停电前15分钟内，配变负载率持续>100%（三相电流均超过额定电流）；② 配变高压侧开关动作类型为"过流保护"，而非差动保护或零序保护；③ 台区下全部用户同时停电；④ 停电时间集中在高温天气日间高峰期（夏季12:00-22:00）或冬季采暖高峰；⑤ 降低负荷后（切除部分负荷或等待用户自然降负）可成功合闸送电 |
| **判定阈值** | 满足①+②+③+⑤判定为高置信度 |
| **与其他原因区分** | 与"配变过热/绕组烧损"(1.1.1)的区别：过负荷跳闸后合闸成功，配变烧损后合闸不成功。与"10kV馈线故障传导"(5.1.1)的区别：台区过负荷时，仅本台区停电，同馈线其他台区正常；馈线故障时，同馈线多个台区同时停电 |
| **历史典型案例编号** | CASE-LOAD-001（夏季高温日，农村台区大量空调同时开机，负载率达180%跳闸） |

#### 逻辑卡片 2.1.2：单相过负荷（三相严重不平衡）

| 字段 | 内容 |
|------|------|
