# 400V低压配电网停电原因分类树（雄安新区场景）

> **场景说明**：本文档面向雄安新区400V低压配电网停电原因分析系统。雄安新区作为国家级智慧城市示范区，电网具有以下显著特征，与通用台区场景存在本质差异：
>
> - **全地下电缆化**：城区核心区禁止架空线，低压网络全部为地下电缆，无架空线、电杆相关故障
> - **综合管廊敷设**：大量电力电缆敷设于地下综合管廊（与供水、燃气、通信管线共廊），管廊环境成为重要故障诱因
> - **大量在建工程**：新区建设期（2017年至今）地下施工密集，施工破坏电缆是高频故障原因
> - **新型负荷集中**：充电桩密度高、楼宇分布式光伏大量接入、数据中心/政务楼宇负荷密度大
> - **高度智能化**：配变监测终端（TTU）覆盖率接近100%，配网自动化覆盖全区，数据获取条件优越
> - **高可靠性要求**：作为国家级新区，停电影响敏感度高，须快速准确判断停电原因

## 二、与通用场景的关键差异说明

| 类别 | 通用台区场景 | 雄安新区场景 |
|------|------------|------------|
| 线路类型 | 架空线为主，部分地下电缆 | **全地下电缆**，无架空线 |
| 1.2 线路故障 | 断线/接地多为架空线风险 | **电缆热缺陷、接头腐蚀、管廊受损** |
| 3.1 自然灾害 | 大风倒杆、冰雪覆冰是主要原因 | 无倒杆风险，**管廊渗水**成为自然灾害主要诱因 |
| 3.2 外力破坏 | 车辆碰撞电杆、树木压线 | **施工挖断电缆、管廊内施工损伤**（建设期高频） |
| 2类负荷特征 | 以生活负荷为主，谐波源少 | **充电桩、光伏、储能、数据中心**等新型负荷 |
| 新能源影响 | 极少 | **分布式光伏逆流、储能冲击**需专门判断 |
| 数据获取 | TTU覆盖率参差不齐 | **TTU全覆盖**，数据完整，判断置信度更高 |

## 三、各大类核心特征速览

| 大类 | 典型停电范围 | 恢复方式 | 关键判断依据 | 雄安特殊性 |
|------|------------|---------|------------|----------|
| 1. 设备类 | 台区全部或部分用户 | 修复/更换设备后恢复 | 配变/电缆告警、电气量异常 | 管廊温湿度数据可辅助判断 |
| 2. 负荷类 | 台区全部或单相用户 | 降负荷后复位装置 | 负荷曲线、三相平衡度、谐波 | 充电桩/光伏数据纳入分析 |
| 3. 外部环境类 | 施工区域用户或管廊段 | 抢修后恢复 | 施工工单、管廊监控、气象 | 施工审批系统是核心数据源 |
| 4. 用户侧 | 单一用户或极少数用户 | 处理用户侧问题后恢复 | 营销系统、用户侧电气数据 | 充电桩故障需关注 |
| 5. 上级传导 | 台区全部用户 | 上级恢复后自动/手动送电 | 10kV系统状态、OMS计划 | 自动化覆盖全区，响应快 |

## 四、判断优先顺序（雄安智慧城市数据条件下）

雄安新区配网自动化覆盖率接近100%，TTU全量在线，可充分利用系统数据自动化排查：

```
Step 1：检查上级传导原因（5类）——系统自动完成，<30秒
         → 实时查询SCADA系统10kV馈线状态
         → 实时查询OMS停电计划工单
         → 若上级有停电/计划停电，直接确定原因，结束分析

Step 2：排查施工外力破坏（3.2类）——雄安优先级高
         → 查询建设工程施工管理系统：台区500m范围内活跃施工工单
         → 若有施工且时间重合，高置信度判断为外力破坏

Step 3：分析设备类原因（1类）
         → TTU数据分析：配变温度、保护动作类型、重合闸结果
         → 管廊监控系统：管廊温湿度、渗水告警
         → 低压故障指示器：定位故障电缆段

Step 4：分析负荷/新能源类原因（2类）
         → 负荷曲线分析：停电前15分钟负载率和三相不平衡度
         → 充电桩管理系统：停电前台区充电桩总功率
         → 分布式能源管理系统：光伏出力、储能充放电状态
         → 谐波数据：THD-I是否超标

Step 5：排查用户侧原因（4类）
         → 营销系统：欠费状态、远程拉闸记录
         → 停电范围判断：仅单一用户停电则重点排查

Step 6：自然环境原因（3.1类）辅助判断
         → 气象数据：是否有强降雨
         → 管廊监控：管廊内渗水告警
```

## 五、分类设计原则

- **互斥性**：同一停电事件最终归入一个末端类别作为直接主因；若存在复合原因（如施工破坏管廊导致电缆渗水击穿），取直接触发因素为主因，诱因记录在备注
- **穷尽性**：五大类覆盖雄安400V台区的主要停电原因，特别补充了新能源和管廊场景，不留分析盲区
- **可操作性**：每个末端类别对应判断逻辑清单中的具体卡片和数据特征，可被智能体直接调用
- **与雄安数据系统对齐**：分类体系充分考虑雄安新区已部署的智慧城市平台、综合管廊监控系统、建设工程管理系统、充电桩管理系统等特有数据源
