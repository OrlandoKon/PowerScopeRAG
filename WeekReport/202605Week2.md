## 2 PowerScopeRAG Demo 开发进展

### 2.1 雄安新区400V场景停电原因梳理

#### 2.1.1 停电原因分类树

```txt
400V停电原因分类树
├── 1. 设备类原因（配变故障、低压电缆故障、低压开关及保护装置故障、计量及通信设备故障）
├── 2. 负荷类原因（过负荷保护动作、末端低电压引发连锁停电、分布式新能源引发故障）
├── 3. 外部环境原因（自然灾害、施工外力破坏、异物及动物引发短路）
├── 4. 用户侧原因（用户内部故障引发总闸跳闸、欠费停电、用户申请停电）
└── 5. 上级传导原因（10kV馈线故障传导、变电站设备故障传导、上级计划停电）
```

#### 2.1.2 判断逻辑清单

针对34个末端类别，各形成一张结构化逻辑卡片，每张卡片包含：原因名称、所属分类、业务定义、判断所需数据源、关键数据特征、判断阈值、与其他原因区分、历史典型案例编号。

##### 逻辑卡片 1.1.1：配变过热/绕组烧损

| 字段 | 内容 |
|------|------|
| **原因名称** | 配变过热/绕组烧损 |
| **所属分类** | 设备类原因 > 配变故障 |
| **业务定义** | 配电变压器因长期过负荷、散热不良或绝缘老化导致绕组温升超限并烧损，引发全台区停电 |
| **判断所需数据源** | 配变监测终端（TTU）：配变油温/绕组温度、三相电流、有功功率；用电信息采集系统：台区下所有用户停电时刻；配网自动化系统：配变高压侧开关状态及保护动作类型；故障抢修系统：现场勘查记录 |
| **关键数据特征** | ① 停电前1小时内配变油温持续上升，停电时刻配变温度告警（油浸式变压器油温>85°C，干式变压器绕组温度>130°C）；② 停电前配变三相负荷电流超过额定电流（负载率>100%，持续时间>30分钟）；③ 台区下全部用户同时失电，停电时刻与配变高压侧开关跳闸时刻吻合；④ 重合闸不成功（合闸后立即再次跳闸）；⑤ 现场检查发现配变有焦糊气味、绝缘油颜色变深/喷油现象 |
| **雄安补充说明** | 雄安新区夏季制冷和冬季电采暖负荷集中，叠加大量充电桩负荷，配变过负荷风险较高；TTU全覆盖使得温度曲线数据完整，过热判断置信度高 |
| **判定阈值** | 满足①+③+④，判定为高置信度；满足①+②+③，判定为中置信度，需现场确认 |
| **与其他原因区分** | 与"台区总过负荷跳闸"(2.1.1)的区别：过负荷跳闸时配变本身无损坏，减负后可复位断路器恢复送电；配变烧损则无法送电，需更换设备。与"10kV馈线故障传导"(5.1.1)的区别：配变故障时，同馈线其他台区用户不停电 |
| **历史典型案例编号** | XA-DEV-001（雄安某商务区台区夏季充电桩与中央空调负荷叠加致配变烧损） |

#### 2.1.3 数据需求清单

针对34个末端停电原因，梳理出**12个数据域**（8个通用域 + 4个雄安特有域），形成特征字典和规则-特征映射关系。

**12个数据域总体结构：**

| 数据域 | 雄安可用性 |
|--------|-----------|
| 配变监测数据（TTU） | ✅ 全覆盖，高优先级 |
| 低压采集数据 | ✅ 全覆盖 |
| 配网自动化数据（SCADA） | ✅ 全覆盖，秒级响应 |
| 营销业务数据 | ✅ 已有 |
| 停电管理数据（OMS） | ✅ 已有 |
| 气象环境数据（降雨/雷电为主） | ✅ 外部接入（风速/覆冰数据已删除，雄安无架空线） |
| 设备台账数据（PMS） | ✅ 已有 |
| 故障抢修数据 | ✅ 已有 |
| **综合管廊监控数据** ⚡ | 雄安特有：管廊温湿度、渗水液位、振动告警 |
| **充电桩管理数据** ⚡ | 雄安特有：充电功率占比、直流快充谐波、绝缘告警 |
| **分布式能源管理数据** ⚡ | 雄安特有：光伏出力/逆流、储能模式切换、逆变器故障码 |
| **建设工程施工管理数据** ⚡ | 雄安特有：施工工单、GIS空间叠加、电力保护许可 |

**雄安场景的主要调整：**
* 删除架空线相关的风速、覆冰气象特征（全地下电缆，不适用）
* 新增管廊渗水、振动告警特征（对应1.2.3 管廊内电缆受损、3.1.2 管廊渗水）
* 新增充电桩谐波、直流快充数量特征（对应2.2.1 充电桩谐波污染）
* 新增光伏逆流方向（`trafo_power_direction`）和储能模式切换时刻特征（对应2.4类 分布式新能源引发故障）
* 新增施工GIS空间叠加特征（`construction_location_overlap`）（对应3.2.2 管廊内施工损伤）

**特征字典规模：**共定义约55个特征字段，覆盖配变运行、低压采集、上级电网、气象、营销、设备台账、管廊监控、充电桩、分布式能源、施工管理等10个特征域。

### 2.2 知识库文档构建

按RAG知识库的核心原则（"LLM不知道或容易答错的内容才有检索价值"）构建doc/目录，最终结构如下：

```
doc/
├── regulations/          # 行业标准与技术规范（7份）
│   ├── GB 50054-2011.md                              # 低压配电设计规范
│   ├── GB 50217-2018.md                              # 电力工程电缆设计标准
│   ├── GBT+13955-2017.md                             # 剩余电流动作保护装置安装和运行
│   ├── GBT+45418-2025.md                             # 低压电力用户供电安全规范
│   ├── 12325-2008-gbt-e-300.md                       # GB/T 12325 电能质量—供电电压偏差
│   ├── 15543-2008-gbt-e-300.md                       # GB/T 15543 电能质量—三相电压不平衡
│   └── DL／T+2806—2024+智能配电台区技术导则.md
└── paper/                # 行业研究论文（9份）
    ├── 台区低电压及重过载研究分析_李飞.md
    ├── 光伏-储能联合系统容量配置优化技术研究_袁诚.md
    ├── 关于分布式光伏接入对低压配网（台区）电压及线损影响研究_徐炜.md
    ├── 分布式光伏发电对低压台区线损的影响与对策分析_臧海岗.md
    ├── 分布式光伏对低压台区线损的影响研究_梁亚明.md
    ├── 含分布式光伏的低压台区三相线损理论计算及其无功优化_李涵.md
    ├── 基于数据驱动的含分布式光伏低压配电网线损异常研究_陈思远.md
    ├── 基于虚拟电厂（储能聚合）的不停电台区研究与应用_吕意飞.md
    └── 考虑分布式光伏逆变器的低压配电台区过电压自动化治理_刘阳.md
```

**文档选取原则：**

* **regulations/**：覆盖400V低压配电网的核心判断依据——电能质量阈值（GB/T 12325、15543）、低压配电设计规范（GB 50054）、漏电保护器安装规程（GBT 13955）、智能台区技术导则（DL/T 2806）等。LLM 对具体阈值数值（如电压偏差±7%、三相不平衡度限值）和操作规程细节容易答错，检索价值高。
* **paper/**：覆盖雄安新区停电原因分析的典型场景——低电压/重过载成因分析、分布式光伏逆流与谐波影响、储能系统对台区的影响等。LLM 对国内配网运维的实证数据和具体案例了解有限，检索价值高。

**文档格式处理：**原始 docx 文件通过 `convert_docx_to_md.py` 脚本批量转换为 Markdown 格式，保留标题层级（`# ## ###`）、段落、有序/无序列表和表格结构，以便百炼平台按章节语义边界进行递归切片。
