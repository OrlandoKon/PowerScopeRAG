## 2 Demo开发进展

### 2.1 业务框架（对应正式项目：停电原因分类体系与判断逻辑清单）

以金融反欺诈为替代域，完成了与正式项目业务层平行的框架搭建，旨在验证"欺诈类型分类树 → 判断逻辑卡片 → 数据需求清单"的整体业务建模方法。

#### 2.1.1 欺诈风险分类树

构建了包含5大类、16个末端类别的欺诈风险分类树，设计原则为互斥性、穷尽性、可操作性与数据集对齐：

```
欺诈风险
├── 1. 身份冒用欺诈（盗用身份、信用卡盗刷、伪造材料、账户接管）
├── 2. 交易欺诈    （刷单套现、分拆交易、高频小额试探、异常时空交易）
├── 3. 信用欺诈    （首贷即骗、多头借贷、养号欺诈、信息包装）
├── 4. 洗钱/资金异常流转（快进快出、分散转移、循环转账、跨境异常转移）
└── 5. 团伙欺诈    （中介代办、刷单团伙、内外勾结）
```

#### 2.1.2 判断逻辑清单

针对16个末端类别，各形成一张结构化逻辑卡片，每张卡片包含：原因名称、所属分类、业务定义、判断所需数据源、关键数据特征（3-6条）、判定阈值、与其他类型的区分要点、历史典型案例参考。

#### 2.1.3 数据需求清单

按"欺诈类型 → 规则 → 特征 → 原始字段 → 数据源"五层结构，整理了涵盖身份设备、交易行为、信用申请、资金流向、团伙关联五个维度共32个核心特征，设计了6张原始数据表（用户信息表、设备日志表、交易表、账户流水表、征信数据表、图谱关系表），并对各数据项进行了优先级标注（P0/P1/P2）。

### 3.3 RAG流水线（第一版）

2. **文本分块**：采用递归切片（RecursiveCharacterTextSplitter），初始切片大小512 Token，重叠128 Token
3. **向量嵌入**：使用本地BGE中文模型（BAAI/bge-small-zh-v1.5）生成向量
4. **向量存储**：存入ChromaDB本地向量数据库
5. **检索测试**：用20个测试问题评估Top-K检索召回效果，调整关键参数
