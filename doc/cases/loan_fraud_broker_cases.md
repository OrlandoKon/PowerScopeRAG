一、中介代办骗贷典型案例
1.1 中介代办骗贷的产业链结构
中介代办骗贷已形成完整的黑色产业链，主要角色包括：上游获客团队（通过企业信息App搜集企业负责人联系方式，电话营销拉客）、中游包装团队（负责伪造营业执照、银行流水、收入证明等材料）、下游对接团队（与银行客户经理对接，推动贷款审批通过），部分链条还涉及银行内部人员的配合。
1.2 典型案例一：无锡千家小微企业助贷诈骗案（2025年判决）
2025年11月，江苏无锡惠山区法院对一起涉案金额达3250万元、涉及高息贷款3亿余元的诈骗案作出判决。犯罪团伙以"助贷"机构为幌子，利用小微企业的资金压力，编织"高额低息零服务费"贷款骗局，受害企业超过千家。
该团伙组织严密，设4个销售部及后勤财务部门，每个销售部设总监管理四五个梯队，每个梯队由梯队长和若干业务员组成。他们通过企业信用信息App搜集目标，编写标准化话术资料，由业务员拨打企业负责人电话约来面谈，随后诱导客户在实际高息的贷款平台上办理贷款，以服务费名义收取钱款。首批18名被告人被判处有期徒刑十二年至二年不等。
风控识别特征： 多个不同企业的贷款申请在短时间内由同一批中介人员提交；申请材料在格式、用词上高度相似；贷款申请的业务员提成记录可关联多个受害企业。
1.3 典型案例二：虚构贸易背景空壳公司骗贷亿元案（2024年判决）
2018年至2023年间，犯罪人缪某通过注册、收购、代为管理等方式取得数十家空壳公司的经营控制权。2021年起，缪某明知无还款能力，仍指使他人制作虚假贸易合同、对应资金走账交易记录、开具发票，制造上述公司存在大量商品贸易的假象，虚构经营能力，骗得6家金融机构无抵押经营性贷款共计1.02亿余元。截至立案时，未归还贷款本金5000余万元。2024年7月，法院以贷款诈骗罪判处缪某有期徒刑十二年三个月。
风控识别特征： 贷款企业注册时间短但交易流水异常大；多家企业之间存在高频关联交易，且交易金额与企业规模不匹配；贷款资金用途与申报的经营范围不一致。
1.4 典型案例三："白户"包装骗贷流窜作案团伙（2025年判决）
犯罪团伙专门挑选无信贷记录的"白户"，采取伪造虚假工作证明、虚构个人账户交易流水等方式进行"包装"，骗取银行消费信贷资金后恶意逃废银行债务。团伙分工明确、流窜作案，短期内在全国多个省市制造多起骗贷案件。主犯被判处有期徒刑十二年六个月。
风控识别特征： 申请人为征信"白户"（无历史信贷记录）；申请手机号为近期新开卡号；工作证明单位在工商系统查无此公司或注册时间极短；银行流水呈现高度规律性（固定日期、固定金额入账）。
1.5 典型案例四：经营贷全链条造假
据媒体暗访调查，部分信贷中介通过以下手段包装客户骗取经营贷：第一步，帮客户注册空壳营业执照（费用仅几百元）；第二步，"养"银行流水3-6个月（通过刷流水300元、找实体挂靠600元等方式制造虚假经营记录）；第三步，对接银行客户经理安排下户核查（部分中介支付下户费300元打通审核环节）；第四步，贷款下款后收取贷款金额1%-3%的服务费。中介通过多个空壳公司账户多次转账掩盖资金流向，贷款资金最终被挪用于购房、炒股等禁止用途。
风控识别特征： 营业执照注册时间短（不满一年）；经营地址与执照地址不一致（工商系统显示异常）；银行流水入账来源单一且金额规律；贷后资金快速转移至非经营用途账户。
